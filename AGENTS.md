# Project guidance

- Keep this repository an instruction-based skill; avoid runtime dependencies unless a demonstrated workflow needs them.
- Maintain the approval boundary in `SKILL.md`: evaluate first, implement the approved scope, and reuse explicit existing authorization.
- Keep the English, German, Simplified Chinese, and Japanese READMEs equivalent. `SKILL.md` is the workflow source of truth.
- Use `TESTING.md` for behavioral regression scenarios. Validate skill metadata and relative Markdown links after relevant edits.
- Never commit credentials, private project evidence, or machine-specific paths. Keep local scratch work in ignored `.scratch/`.
- Do not maintain a changelog for this project.
